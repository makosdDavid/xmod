# xmod

Second-screen companion and helper tools for X4: Foundations 9.00.

- `companion/` - in-game bridge mod (`mod/`) + local server and web dashboard (`server/`): live map, property,
  logbook, missions, factions. Runs on 127.0.0.1 only. See `companion/server/README.md`.
- `prototype-v0/` - the first proof-of-life version (sector map only).
- `x4span/` - experimental window-spanning presets for multi-monitor tests.

No game data is included. `static_map.json` is generated locally from your own game files.
Work in progress.
